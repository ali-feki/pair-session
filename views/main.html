Frequently Asked Questions

Quick answers before you pair.

Which pairing method should I use?

Use Pair-Code if you only have one phone. Use QR Scanner if you can scan the code from a second device.

The pairing code does not work. What now?

Codes expire quickly. Generate a new one and enter it right away in WhatsApp under Linked Devices.

How do I see the commands after pairing?

Send .menu to the bot in any chat to list every available command.

Where do I get help or updates?

Join the WhatsApp Updates channel or use Contact Developer in the footer.
